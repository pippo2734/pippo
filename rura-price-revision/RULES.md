# 改定対象セルのルール

「料金表の月会費セルだけを、座標指定で、注記を壊さず改定する」ための判定・操作ルール。
Phase 0（福岡西新 DAG_Z6db2XA, 2026-06-21）の実証に基づく。

---

## 1. 改定対象セルの判定（ALLを満たすセルだけが対象）

1. **指定された料金表の中にある** — `revision_plan.csv` に列挙した `table_id` の表のみ。
   ページ上の任意の表を勝手に対象にしない。
2. **金額列にある** — 表セルID `<tableID>-<列><行>` の **B列**（A列はラベル）。
   ※ 表によって金額列が違う場合は `revision_plan.csv` の `target_column` で上書き指定。
3. **月会費の行である** — 月会費の項目行のみ。
4. **金額レンジのガード内** — 例: ¥1,000〜¥30,000。レンジ外は対象外（誤爆防止の保険）。

> 「全部の数字 + デルタ」は **NG**。振替差額165円・入会金・事務手数料・営業時間9:00・
> 年齢・回数・級・時刻を巻き込むため。対象は **料金表の月会費セルに限定**する。

## 2. 除外対象（絶対に触らない）
- 入会金 / 事務手数料 / 振替差額（例 165円）
- 営業時間（9:00 等の時刻）/ 電話番号 / 日付
- 年齢 / 回数 / 級 / コマ数などの数値
- ラベル列（A列）のテキスト

## 3. 衝突回避（同額セルの撃ち分け）
- 同じ金額が複数セルに出る場合（例: 12,430円が正会員 / セルフプラス / 別表に存在）でも、
  **必ずセルID（座標）で狙った1セルだけ**を変更する。
- **値マッチ（find & replace を表全体・デザイン全体に）で金額を改定してはいけない**。
  同額の別項目を巻き込む。

## 4. 操作方式（注記を壊さない）
- **複数行セル（金額 + 注記、例「12,430円（火・木）」）** は、`find_and_replace_text` で
  **金額の部分文字列だけ**を置換する。
- `replace_text`（セル全文置換）は注記が消えるので**使わない**。
- 単一値セルは set/replace でも可だが、原則 find_and_replace_text に統一すると安全。

## 5. セルIDの取得（最重要の落とし穴）
- 表セルID = `<tableID>-<列><行>`（例 `-B2`）。A列=ラベル、B列=金額。
  マージ/複数行セルはサフィックス付きID。
- **IDは「編集対象のデッキ自身」から読む**こと。
  - フル複製（`copy-design` の全ページ）は要素IDを**保持**する。
  - 抜粋ページ複製（`page_numbers` 指定）は要素IDが**振り直される** → 抜粋コピーのIDは
    元デッキに当たらない。
- ページ特定は `get-design-content`(pages指定) を使う。
  対話UIだと `start-editing-transaction` の構造が大きすぎて（〜25kトークン）途中で切れ、
  後半ページのIDが読めないことがある。

## 6. 方式Aの検証ゲート（本番適用の前提）
1. 本番デッキを**フル複製**（before バックアップ）。`clubs.csv` に複製IDを記録。
2. 複製上で対象セルIDと**旧値**を確定し、`target_cells_<design_id>.csv` に書き出す。
3. 複製上で改定を適用 → サムネ/内容で目視検証。
4. 検証OKの操作だけを**本番の既存URL**に適用（URL不変）。
5. 本番適用後、`target_cells_*.csv` を差分レポート（旧→新）として保管。
