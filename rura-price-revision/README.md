# RURA価格改定 帳票自動化（2026年10月改定）

Canva料金帳票（約100クラブ）を、クラブごとの一律デルタで自動改定する仕組み。
Claude Code × Canva コネクタで、ぴっぽ一人運用を目指す。

## ゴール
2026年10月の価格改定で、約100クラブのCanva料金帳票を修正する。
- クラブ**内**は一律デルタ（例: 会員種別 +300円）
- クラブ**間**でデルタが違う
- 8月のクラブ告知前に仕組みを用意する

## 運用モデル＝方式A（確定）
1. 改定前を新規URLに丸ごと複製して保管（before = バックアップ / ロールバック用）
2. クラブに共有済みの既存URLは中身だけ改定後に書き換え（after）。URL不変＝共有齟齬ゼロ
3. 本番では実験しない。複製で検証 → 検証済みの操作だけを本番に適用

## このフォルダの構成
| ファイル | 役割 |
|---|---|
| `README.md` | 全体像（このファイル） |
| `RULES.md` | **改定対象セルのルール**。どの表のどの列を改定対象とみなすか／除外対象／衝突回避 |
| `clubs.csv` | クラブ登録簿。クラブ → 本番design_id → before複製ID → ステータス |
| `revision_plan.csv` | 改定計画。(クラブ × 区分) ごとのデルタと対象表（page / table_id / 列） |
| `target_cells_<design_id>.csv` | 検証で確定した**適用マニフェスト**。1行=1セル（旧→新）。差分レポートも兼ねる |

データの流れ:
```
clubs.csv（どのクラブを） 
  → revision_plan.csv（どの区分に何円のデルタを）
    → 検証（before複製で対象セルを特定・旧値取得）
      → target_cells_<id>.csv（確定した1セルずつの旧→新マニフェスト）
        → 本番適用（マニフェスト通りに書き換え）＝差分レポート
```

## Phase 1 確定事項（2026-06-23）
1. **マスター表の置き場所＝リポジトリ内CSV**（clubs / revision_plan / target_cells）。
   差分が履歴に残り、Phase 3のループからそのまま読める。
2. **「改定対象セル」の確定方式＝クラブ別の検証済みセルID一覧**。
   before複製で対象セルIDと旧値を1回確定 → `target_cells_<id>.csv` に固定 → 本番はその通りに適用。
   `RULES.md` の判定ルールは「マニフェストを作るための検証時フィルタ」として使う。
